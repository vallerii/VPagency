# VP agency — концепция и дизайн

## Часть 1 · Концепция (выбрано 29.10.2026)
- **Направление:** G «Стена ситуаций», по референсу niccos.com (третий круг; A–F отклонены).
- **Идея:** текст слева, справа две медленные колонки карточек с шестью ситуациями клиента; вместо фото брендов — нарисованные предметы ситуаций (таблица, форма, корзина, переписка, переезд, ИИ).
- **Мотив:** мягкая карточка с нарисованным предметом и подписью снизу — ситуации, шаги и проекты говорят одним языком.
- **Живая вещь:** колонки едут навстречу друг другу; нажатие на карточку ведёт на страницу ситуации.
- **Отклонено:** A–F (фраза и лента, тихий инструмент, папка с итогом, имя по центру, деловое письмо, ось) — «не нравится».

## Часть 2 · Дизайн-система (прототип /neu)
- **Шрифты:** заголовки Geist 400 (самохостинг, /public/fonts/geist, SIL OFL; замена Neue Montreal из референса), текст Manrope (уже есть в проекте).
- **Цвет:** фон #fefefe, текст #161310, вторичный #6f655b (AA), линии #ebe7e2; пять тёплых оттенков карточек (mist, clay, sand, warm, sage); красный #a8402a только для «ошибки» внутри предметов.
- **Форма:** кнопки и меню — полностью круглые таблетки; карточки — радиус 14–22px.
- **Ширина:** без ограничения 1440: поля clamp(20px, 5vw, 128px), размеры текста растут до 2560.
- **Код:** src/content/home.ts (тексты DE + RU для проверки), src/components/home/*, страница src/app/neu/page.tsx (noindex). Старая главная не тронута.
- **Анти-лист:** список услуг, цены, жаргон в hero, «KI» как лозунг, стоковые картинки, логотипы технологий на первом экране, неподтверждённые цифры.
